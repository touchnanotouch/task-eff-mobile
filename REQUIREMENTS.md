# Задача

Спроектировать и реализовать на Go (Golang) RESTful HTTP-сервис для управления подписками пользователей и агрегации их стоимости.

# Требования

### 1. CRUDL-операции над подписками

Реализовать HTTP-ручки для создания, чтения, обновления, удаления и получения списка записей о подписках.

**Поля записи:**

- `service_name` — название сервиса (string)
- `price` — стоимость подписки в рублях (целое число, int)
- `user_id` — идентификатор пользователя (RFC 4122 UUID)
- `start_date` — дата начала (месяц и год) в формате `MM-YYYY`
- `end_date` — дата окончания (опционально, `null` или не передавать), формат `MM-YYYY`

**Примечания:**

- Проверка существования пользователя НЕ требуется.
- Копейки не учитываются (целые рубли).

**Пример запроса на создание:**

```json
{
  "service_name": "Yandex Plus",
  "price": 400,
  "user_id": "60601fee-2bf1-4721-ae6f-7636e79a0cba",
  "start_date": "07-2025"
}
